Safety guarantees

The controls implemented in this build, not future promises.

Tested
✓

Default deny

Unknown tools and invalid arguments are rejected before execution.

✓

Workspace confinement

Reads and writes outside the approved workspace are blocked, including symlink escapes.

✓

Approval binding

Approvals are single-use, expiring, and bound to the exact tool name and arguments.

✓

Fail closed

Policy evaluation errors and unexpected tool validation errors produce a denial.

Current scope: one real read-only tool, no persistent event store, and no approval queue/UI yet. The safety gate and its denial/approval behavior are covered by tests; a full agent runtime is still on the roadmap.
